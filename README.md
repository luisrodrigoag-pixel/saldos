# Saldos

Página de saldos por cuenta, para consulta de la dirección.

Se publica en https://luisrodrigoag-pixel.github.io/saldos/ y se regenera desde el
histórico con `publicar.py`. Los números de cuenta salen enmascarados a los últimos
cuatro dígitos: la página es pública y para ver un saldo no hace falta el número
completo.
